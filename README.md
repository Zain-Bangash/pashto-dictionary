# Pashto Dialect Revival Dictionary

## Overview

The Pashto Dialect Revival Dictionary is a full-stack web application designed to preserve and document a declining local dialect of Pashto.

The project combines software engineering, data collection, and linguistic validation to build a structured, community-driven dictionary system.

---

## Motivation

My local dialect of Pashto is gradually declining, as native vocabulary is increasingly replaced by foreign loanwords. As a result, many original words are being forgotten, particularly among younger speakers.

A key factor contributing to this decline is the lack of an accessible, structured, and community-driven digital dictionary that preserves and standardises regional dialects.

---

## Project Evolution

This project has evolved over time alongside my technical growth:

- **Initial Version:** Built using Spring Boot as a basic backend system
- **Second Iteration:** Rebuilt using the MERN stack for improved flexibility and usability
- **Current Version:** A complete redesign leveraging modern development practices, AI-assisted workflows, and human validation

The current version focuses on combining:
- Scalable full-stack architecture
- Community-driven contributions
- Human-in-the-loop validation

---

## Key Features

- Community-driven word submissions
- Structured dictionary of dialect-specific vocabulary
- Searchable lexicon interface
- Word verification and moderation workflow
- Annotation of unverified or uncertain entries

---

## Data Collection and Validation

This project goes beyond software development and includes significant work in data collection, cleaning, and linguistic validation.

The dataset is built from:
- Personal knowledge of the dialect
- Contributions from elders and community members
- External academic and linguistic sources where available

---

## Verification Process

Each submitted word undergoes a structured validation process:

- Consultation with native speakers and elders
- Cross-referencing with linguistic research papers and references
- Verification against available online sources where applicable

If a word cannot be fully verified, it is still included in the dictionary but clearly marked with a cautionary note to indicate uncertainty.

This approach prioritises transparency while preserving linguistic diversity.

---

## Vision

The long-term goal of this project is to preserve and revitalise the Pashto dialect by enabling structured documentation, contribution, and learning.

It is not only a software system, but also an effort to preserve linguistic and cultural heritage through technology.
